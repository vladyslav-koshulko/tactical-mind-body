# Tactical Mind & Body

Офлайн-приложение для психофизических Dual-Task тренировок: круги калистеники,
чередующиеся с когнитивными задачами в паузах. UI на русском, военно-тактическая
CRT-эстетика.

**Ссылка на свежую сборку (без логина) — давать в начале каждой сессии:**
https://github.com/vladyslav-koshulko/tactical-mind-body/releases/latest/download/tactical-mind-body-debug.apk

## Где мы сейчас

Продукт — HTML-прототип `www/index.html` (966 строк ванильного JS) в обёртке
Capacitor. Он работает и собирается в CI. Принято решение переписать всё на Flutter;
Flutter-скелет (workspace: `packages/tmb_domain`, `tmb_data`, `tmb_ui`, `apps/mobile`)
уже компилируется, но экранов и логики в нём ещё нет.

Текущий этап — Фаза 1 (`docs/ROADMAP.md`): модели и валидатор в `tmb_domain`, тема и
пустой дашборд в `tmb_ui`, логотип/иконка. Контракты данных — `docs/SCHEMAS.md`.

**Flutter не в PATH.** SDK лежит в `~/development/flutter`; в командах:
`export PATH="$HOME/development/flutter/bin:$PATH"`. Хук `dart-check` без этого молчит.

## Инварианты — нарушать нельзя

Это решения, которые дорого менять потом. Обоснования — в `docs/ARCHITECTURE.md`
и `docs/EXTENSIBILITY.md`; здесь только сами правила.

1. **`tmb_domain` — чистый Dart, ноль импортов `package:flutter/…`.** Это
   единственное, что делает будущий порт на Wear OS / watchOS дешёвым.
2. **Сырые события с первого релиза.** Пишем `TaskAttempt` с `roundIndex`,
   `latencyMs`, `isCorrect`, `payloadHash` по каждой попытке — не агрегаты. Кривую
   деградации невозможно восстановить задним числом; без этого вся аналитика v0.3 и
   лидерборды v0.5 стартуют с пустой историей.
3. **Тема ≠ тип задачи.** Механик ровно семь: `recall`, `choice`, `ordering`,
   `delayed_recall`, `spatial`, `stream`, `verbal`. Java, такмед, латынь — это
   *контент* поверх них. Класс вида `JavaTask` или `TacmedTask` — ошибка
   проектирования: новый домен должен добавляться файлом пака, а не правкой кода.
4. **`generate(seed)` детерминирован.** Одинаковый сид → одинаковая задача. Без
   этого невозможны дуэли, честные лидерборды и воспроизведение сессии.
5. **Сессия — список блоков** (`PhysicalBlock` / `CognitiveBlock` / `RestBlock`), а
   не жёсткое «круг → пауза». Отсюда бесплатно получаются «только физика», «только
   когниция» и кастом.
6. **Цвет фазы:** зелёный `accent500 #A6FF4D` = физика, оранжевый `signal500 #FF8A1F`
   = когниция. Фаза **обязана** дублироваться нецветовым каналом (форма, звук,
   вибро) — пара плоха для дейтеранопии.
7. **`verbal` не влияет на Индекс и лидерборды** — он не проверяется машиной.
8. **Клиент никогда не отправляет свой счёт.** Только сырые события; индекс считает
   сервер.
9. **Локализация с первой строки.** UI — ARB (`ru`, `uk`), ни одной строки в коде
   виджета. Контент задач — **не** ARB, а данные в `assets/content/<locale>/`:
   задачи вроде «без слов с буквой О» непереводимы дословно.
10. **Реклама** — только статичный нативный баннер на дашборде и в архиве. Никогда
    во время физической или когнитивной фазы.

## Дизайн

Токены — `packages/tmb_ui/lib/tokens.dart` (единственный источник правды в коде), Figma —
`docs/DESIGN.md`. Шрифты: **Oswald** (display, всегда капсом) + **JetBrains Mono**
(данные). Условные фаворитные condensed-гарнитуры (Chakra Petch, Rajdhani, Barlow
Condensed) **не имеют кириллицы** и молча подменяются — при любой смене шрифта
проверять кириллицу, включая украинские `і ї є ґ`.

## Сборка

```bash
npm install && npx cap sync android && cd android && ./gradlew assembleDebug
```
Чистая сборка **требует** `npx cap sync android`: каталоги
`android/capacitor-cordova-android-plugins/` и `android/app/src/main/assets/public/`
генерируются и не лежат в репозитории.

CI (`.github/workflows/build-apk.yml`) собирает APK на каждый push в `main` и
публикует GitHub Release. Если убрать шаг публикации релиза — постоянная ссылка выше
умрёт; восстанавливать, а не откатываться на artifact-ссылки.

## Как работать в этом репозитории

- Документация проекта — на русском. Комментарии в коде — тоже.
- Перед коммитом прогонять `invariant-check` (агент) на диффе.
- Крупные архитектурные решения — записывать в `docs/ARCHITECTURE.md`, а не только
  в коммит. Документы здесь — рабочий инструмент, а не отчётность.
