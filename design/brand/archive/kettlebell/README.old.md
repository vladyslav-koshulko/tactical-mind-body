# Бренд: метка и иконка

Метка — **гиря с вырезом в форме схематичного мозга** (два полушария и центральная
линия). Гиря = тело (калистеника), мозг в корпусе = разум (когнитивная пауза).
Центральная линия — единственный оранжевый акцент (`signal500`), остальное зелёное.
Гексагон остаётся фирменной формой в `mark-alt.svg` и в декоре фона иконки.
Все SVG чистые: только `<path>`, без текста, без растров, без внешних ссылок.
Цвета — только токены `packages/tmb_ui/lib/tokens.dart`.

## Что есть что

| Файл | Размер | Назначение |
|---|---|---|
| `mark.svg` | 512×512, прозрачный фон | Основная метка. Сплэш, шапка, «О приложении», README, соцсети. |
| `mark-alt.svg` | 512×512, прозрачный фон | Альтернатива для выбора владельцем: расколотый гексагон (слева сплошной = тело, справа контур с узлом = разум). Это **другая идея формы**, а не перекраска. |
| `icon-foreground.svg` | 108×108 | Передний слой адаптивной иконки Android. Всё содержимое внутри круга диаметром 66 по центру (проверено: максимальный радиус вершин = 32 из 33). |
| `icon-background.svg` | 108×108 | Задний слой: `surface #0B1210` + тонкий декор (концентрические гексагоны, угловые метки прицела) цветом `borderSubtle`. |
| `icon-monochrome.svg` | 108×108, прозрачный фон | Слой для тематической иконки Android 13+. Одна заливка; система сама перекрашивает по альфе. Та же безопасная зона. |
| `icon-1024.svg` | 1024×1024, непрозрачный, без скруглений | Иконка для магазина (Google Play / App Store). Скругления накладывает платформа. |
| `preview.png` | — | Контрольный лист: метки 512/96/48/24 на тёмном и светлом, иконка кругом и скруглённым квадратом, монохромный слой. Не для публикации. |

## Где что применять

- **Android adaptive icon**: `icon-background` + `icon-foreground` (+ `icon-monochrome`
  как `<monochrome>`). Растеризовать в PNG/Vector Drawable на этапе Flutter-скелета
  (`flutter_launcher_icons` или вручную); в `android/` этот каталог ничего не меняет сам.
- **Магазин**: `icon-1024.svg` → PNG 1024 (Play берёт 512×512, App Store — 1024×1024 без альфа-канала).
- **Внутри приложения** (сплэш, пустые состояния): `mark.svg`.
- Метка **ничего не пишет текстом**. Если нужен логотип с названием — слово
  «TACTICAL MIND & BODY» (Oswald, капс) набирать в UI-слое или перевести в контуры;
  в сам SVG-файл метки текст не добавлять.

## Минимальные размеры и охранное поле

- Метка: не меньше **24 px** по высоте (на 24 px это уже силуэт: мозг в вырезе не различим, виден лишь «разделённый» вырез);
  в интерфейсе по возможности ≥ 32 px. Для иконок меньше 24 px — только `icon-monochrome`.
- Охранное поле: **25 % ширины метки** с каждой стороны (для 512 px — 128 px). Внутри поля
  ничего не размещать.
- Иконка: контент держать внутри круга Ø 66 из 108; всё вне круга может быть обрезано маской.

## Цвет и доступность

- Главный цвет метки — `accent500 #A6FF4D`; ядро — `signal500 #FF8A1F` (физика / когниция).
- **Смысл не держится на паре зелёный/оранжевый** (инвариант 6): оранжевая линия — это
  центральный разделитель полушарий (форма и положение), и метка читается в один цвет —
  см. `icon-monochrome.svg`.
- Метка рассчитана на **тёмный** фон (`void_`, `surface`). `accent500` на светлом фоне
  имеет низкий контраст — на светлом ставить метку только на тёмной плашке `surface`.

## Чего нельзя делать

- Нельзя перекрашивать метку и менять пары цветов (оранжевый корпус + зелёное ядро и т. п.);
  вводить цвета вне токенов.
- Нельзя добавлять обводку, тени, градиенты, свечение, скругление углов — эстетика «почти острый угол».
- Нельзя растягивать непропорционально, вращать, наклонять.
- Нельзя убирать вырез-мозг или центральную линию, «упрощая» метку: без них она превращается в пустой силуэт гири. Нельзя добавлять извилины — на 48 px они пропадают.
- Нельзя делать оранжевым корпус или ставить метку на оранжевый фон.
- Нельзя использовать оранжевый акцент без зелёного корпуса (оранжевый — только смысловая точка).
- Нельзя класть на метку текст и закладывать в SVG `<text>` — шрифты подменятся молча.
- Нельзя применять `icon-1024.svg` с предварительным скруглением или прозрачностью.

## Открытое

- Мозг в вырезе узнаётся как мозг только от ~96 px; на 48 это два полушария с линией,
  на 24 — разделённое окно. Так и задумано (детали убраны), но не как «мозг» с первого взгляда.
- Риск «замок» снижен (широкая ручка, круглый корпус, плечи), но на 24–48 px полностью не
  исчез: ручка с отверстием + корпус с вырезом всё ещё может читаться как навесной замок.
  Решать после проверки на реальном экране телефона.
- Эти SVG написаны вручную (генератор не хранится); при правке держать вершины в безопасной зоне.
