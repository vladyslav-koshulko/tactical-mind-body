# Дорожная карта — Tactical Mind & Body

Приоритет: **мобильное приложение (Android) → iOS → часы.**
Технические решения, лежащие в основе, — в [ARCHITECTURE.md](ARCHITECTURE.md).
Контракты расширяемости (домены задач, паки, виджеты, темы) — в
[EXTENSIBILITY.md](EXTENSIBILITY.md).

## Принцип нарезки релизов

1. **Каждый релиз устанавливается на телефон и им можно пользоваться.** Нет
   «инфраструктурных» релизов, которые ничего не дают пользователю.
2. **Сначала то, что дорого переделать.** Модель данных, локализация, доменный слой —
   в самом начале, даже если их плоды видны только через три релиза.
3. **Монетизация — после удержания.** Продавать подписку в приложении, куда не
   возвращаются, бессмысленно: сначала аналитика и соцфичи, потом paywall.

### Про сроки — честно

Расхожая оценка «всё за 2–3 недели и 45 $» описывает **v0.1**, а не этот документ.
Скелет на Flutter с ИИ действительно собирается за считанные дни. Но лидерборды с
античитом, аналитика, ревью Google Play, платёжные тесты и полировка — это месяцы
календарного времени, значительная часть которого уходит на ожидание ревью, а не на
код. Ниже вместо дат — **относительный размер** (S / M / L) и критерий готовности.

## 🎖 v0.1 «РЕКРУТ» — паритет на настоящей архитектуре

**Размер: L** · Первый Flutter-релиз

Функционально повторяет HTML-прототип, но стоит на фундаменте, который выдержит всё
остальное.

- [x] **Сессия как список блоков** (`PhysicalBlock` / `CognitiveBlock` / `RestBlock`) —
      открывает «только физика», «только когниция» и кастом без переписывания движка.
      Движок и планировщик — `tmb_domain/engine`, 66 тестов; **экранов пока нет**
- [x] **Контракт `CognitiveTaskProvider`** + семь архетипов задач вместо тем
- [x] **Детерминированная генерация по сиду** — без неё невозможны дуэли и честное
      сравнение в лидербордах
- [x] Схема тегов задачи: домен, уровень, локаль, сложность, проверяемость
- [x] Декларативный формат контент-пака (v0.1 везёт только встроенные паки) и
      **валидатор** — он же проверяет встроенные паки в CI
- [x] **Категории с галочками** и разделы «Проверяемые» / «Непроверяемые» (R3):
      включённость в профиле, фильтр пула, минимальный экран
- [x] **Задачи на неопределённость**: встроенный пак [`uncertainty.pack.json`](../assets/content/ru/uncertainty.pack.json),
      подсказки `cues` (смена правила посреди задачи), чек-лист самопроверки
- [x] **Per-exercise цели** вместо одного «N повторений на все упражнения»; единицы
      `reps` / `seconds`; одно нажатие «тяжело / нормально / легко» после круга
- [x] Экспорт пользовательских данных одной кнопкой (сериализация, без UI импорта) — кнопка «Поделиться» в настройках, файл проходит валидатор
- [x] Тренировки **Дом** (калистеника), пул из 15+ упражнений
- [x] 3 типа задач: математика, вербальные, мнемоника — паки `math.arithmetic`, `cog.verbal`, `cog.memory` (100 задач); без генераторов по сиду и выбора из вариантов — v0.2
- [x] Настройки: режим повторений (фикс/диапазон), круги, длительности
- [x] **Полное логирование событий** — `TaskAttempt` с `latencyMs` по каждой попытке
- [x] Локальная БД Drift + миграции — `tmb_data`, 59 тестов; **в приложение не подключена**
- [x] Локализация `ru` / `uk` через ARB с первой строки *(украинские строки не вычитаны носителем)*
- [ ] Сводка сессии в общее хранилище — фундамент под будущий виджет
- [x] Фаза дублируется нецветовым каналом (форма, звук, вибро) — не только зелёный/оранжевый
- [x] Локальная история сессий *(на дашборде — последняя; списка пока нет)*

**Готово, когда:** сессия проходится офлайн от начала до конца, в БД лежат сырые
события для кривой деградации, а **новый когнитивный домен добавляется файлом пака,
а не правкой кода** — это проверяется добавлением тестового пака.

> ⚠️ Это единственный релиз, который почти не добавляет пользователю новых возможностей.
> Цена входа в нормальную архитектуру. Дальше темп резко растёт — и именно эти контракты
> позволяют потом покрыть Java, такмед, латынь и шахматы без переписывания ядра.

- [ ] Уровни сложности: Рекрут → Боец → Оперативник → Спецназ
- [ ] XP, уровни, тактические звания (локально)
- [ ] Тактический дашборд по макетам из Фазы 1
- [ ] Контент через Remote Config — паки и упражнения обновляются без релиза

**Готово, когда:** три локации дают ощутимо разные тренировки, а пользователь может
собрать сессию под себя — разработчик берёт Rust, врач латынь, военный такмед.
