# Контент-пак

**Главное правило: новый домен — это файл данных, а не код.** Если для добавления
темы понадобилось править движок сессии или заводить новый класс задачи — абстракция
применена неверно, остановись и скажи об этом.

Полное обоснование — `docs/EXTENSIBILITY.md`.

## Семь архетипов — других не бывает

| Архетип | Механика | Проверяем машиной |
|---|---|---|
| `recall` | ввести ответ | ✅ |
| `choice` | выбрать из N | ✅ |
| `ordering` | упорядочить шаги | ✅ |
| `delayed_recall` | запомнить сейчас, ответить через круг | ✅ |
| `spatial` | работа с сеткой/картой | ✅ |
| `stream` | поток стимулов на скорость (n-back, Струп) | ✅ |
| `verbal` | произнести вслух, самооценка | ❌ |

Любая тема раскладывается на них. «Дженерики Java», «доза при анафилаксии» и
«перевод латинского термина» — это один и тот же `recall` с разным содержимым.

## Формат

```yaml
pack: mil.tacmed.ru
title: Тактическая медицина — база
locale: ru
domain: mil.tacmed
license: CC-BY-4.0
levels: [recruit, operator]
items:
  - archetype: ordering
    prompt: Восстановите порядок протокола MARCH
    items: [Massive hemorrhage, Airway, Respiration, Circulation, Hypothermia]
    difficulty: 0.35
  - archetype: choice
    prompt: Максимальное время наложения турникета до переоценки
    options: ['30 мин', '2 часа', '6 часов', 'Без ограничений']
    answer: 1
    difficulty: 0.5
```

## Чек-лист при создании

1. **`domain`** — иерархический (`it.java`, `med.latin`, `mil.tacmed`), чтобы
   работал отбор по префиксу.
2. **`locale`** — пак пишется под язык, а не переводится. Задачи вроде «опишите
   комнату без слов с буквой О» дословно непереводимы.
3. **`difficulty`** — 0…1, и она должна быть **сопоставимой внутри пака**. Кривая
   деградации сравнивает круги между собой; если сложность плывёт вместе с номером
   круга, метрика измеряет подбор задач, а не усталость. Это тихая и очень
   убедительная ошибка.
4. **`verbal`-задачи** не влияют на Индекс и лидерборды — машиной не проверяются.
5. **`estimatedTime`** должно помещаться в паузу (по умолчанию 180 с), с запасом на
   чтение условия.

## Регуляторные ограничения

- **Медицина** — только учебный материал, обязательный дисклеймер, никаких
  формулировок, похожих на медицинскую рекомендацию.
- **Военные темы** — терминология и тактика проходят в Play; никаких инструкций по
  изготовлению оружия и взрывчатки, никаких непубличных ТТХ и реальных позиций.
- **Кибербез** — теория, классы уязвимостей, защита. Рабочие эксплойты — нет.

## Проверка

Прогони пак через валидатор, когда он появится. До этого проверяй руками:
все `archetype` из списка семи, у каждого `choice` есть `answer` в границах
`options`, `difficulty` в 0…1, нет дублей `prompt`.
